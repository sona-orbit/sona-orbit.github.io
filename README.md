# sona-orbit.github.io

Root site for Sona Orbit (https://sona-orbit.github.io/).

- `index.html` — the home page (projects, Threads and email contact).
- `*-icon-192.webp` — small product icons (192×192 WebP) shown at 56px on the home page; kept here so the home page does not depend on each product site's file names. `parroting-icon.png` stays as the favicon.
- `googleb3640a59759f7405.html` — Google Search Console verification file. Do not delete it.
- `robots.txt` / `sitemap.xml` — search engine hints. The sitemap also lists the Parroting pages (served from the `sona-orbit/parroting` repo under `/parroting/`); update it when Parroting adds or removes public pages. English pages under `/parroting/en/` are `noindex` for now and are left out.

All site content and commit messages are in English.
